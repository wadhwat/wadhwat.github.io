## Project brief

At Vincilium, I worked on agent infrastructure that turns natural-language questions into
efficient database access, exposes external actions through guarded MCP tools, and learns
reusable tenant-specific behavior without weakening host-level safety rules.

## What I built

- A multistage natural-language query path over PostgreSQL that reduced prompt context by
  83–91% in the measured workflows.
- Eight guarded MCP tools with alias resolution, idempotency, and tests around unsafe or
  duplicate actions.
- An evaluation suite spanning six model backends, with four validated in the target
  environment.
- Typed, tenant-scoped memory and skill lifecycle components with human-controlled
  promotion.
